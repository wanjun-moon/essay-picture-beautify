# Fourteen scientific figure families

| Type | Primary semantic responsibility | Preservation checklist | Suitable refinements |
|---|---|---|---|
| 1. Method architecture | Computational paths and modules | Arrow direction, skip connections, operators, parameters, shared/frozen components | Stage grouping, grid, labels |
| 2. Training and inference workflow | Sequence and state | Input/output, loss gradients, model state, temporal order | Swimlanes, phase color |
| 3. Mathematical/statistical model | Assumptions and relations | Variable names, equation operators, signs, coefficients, path directions | Structured typography and spacious notation |
| 4. Line/learning curve | Trend over independent variable | Data points, units, limits, smoothing, variance, start/stop criteria | Clear strokes, directly labeled series |
| 5. Categorical/bar chart | Comparison across methods/conditions | Category order, zero origin where necessary, groups and error bars | Consistent series colors and spacing |
| 6. Scatter/bubble plot | Multivariate relationships | Axes, encoding for size/color, size legend, scales | Distinct markers and annotation placement |
| 7. Heatmap/confusion matrix | Matrix values | Normalization, percent vs count, row/column meaning, color limits | Legible cell labels and legend |
| 8. Medical/scientific image panel | Visual evidence | Original pixels, orientation, crop, scale, contrast/windowing | Uniform tiles, borders, detached labels |
| 9. Image enhancement comparison | Correspondence between inputs/outputs | Source scene, identical crop/zoom, method identity, reference/GT | Aligned grids, detail insets |
| 10. Maps and spatial graphics | Spatially located measurements | Projection/orientation, color legend, geographic boundaries, missing data | Clear map inset and readable scale |
| 11. Taxonomy/overview | Categories and their scope | Membership, inclusion, intersections, count claims | Structured hierarchy or Venn geometry |
| 12. Knowledge graphs/hypergraphs | Entity and relation semantics | Graph edges, edge types, hyperedges, direction, cardinality | Routing, color coding by relation |
| 13. Prompt/code/questionnaire panel | Exact experimental stimulus | Literal strings, syntax, keys, branching, UI state | Monospaced blocks, panel borders |
| 14. Experimental interface/measurement zones | Measurement apparatus | ROI geometry, coordinate systems, device state, timestamp | Cleaner captions and spacing |

## Cross-cutting distinctions
- Plot annotations and significance labels are scientific content.
- A good color system maps one visual encoding to one stable meaning throughout a manuscript.
- For comparative scientific images, source pixels must not be fabricated, sharpened, denoised or selectively improved as an aesthetic step.
- For any taxonomy, preserve the underlying logic of membership and overlap.
